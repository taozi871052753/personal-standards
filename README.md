# 个人规范库

集中维护个人工作规范、分类标准和验收要求，方便在不同 AI 工具和会话中引用。

## 规范目录

| 文件 | 适用场景 |
|---|---|
| [GITHUB_STARS_RULES.md](GITHUB_STARS_RULES.md) | 按用途与使用状态整理 `taozi871052753` 的 GitHub Stars |

## 如何使用

把具体规范的文件链接发给 AI，并说明要执行的任务。例如：

```text
请读取 https://github.com/taozi871052753/personal-standards/blob/main/GITHUB_STARS_RULES.md，按规范增量整理我的 GitHub Stars，完成后核验并报告结果。
```

AI 应先读取规范全文和当前实际数据，再执行用户授权的操作；无法读取规范或缺少操作权限时应明确说明。

## 维护约定

- 每类任务单独维护一份 Markdown 规范，并在本目录添加入口。
- 规范写明适用范围、执行规则和验收标准；发生规则变化时更新版本和日期。
- 历史数量和状态须注明日期，不作为未来固定目标。
- 用户最新明确要求优先；单次临时要求不自动改成永久规则。
- 本仓库公开，不提交令牌、Cookie、密码或其他敏感信息。
